# Velora Beta - nuova build con Velora Tools

Velora introduce la prima release di Velora Tools: 40 strumenti integrati, divisi in 4 gruppi da 10, disponibili direttamente dentro l'app e indicizzati nella ricerca interna.

## Velora Core
- Wallet Check per validare indirizzi pubblici XMR e ZEPH
- Mining Monitor con stato worker, hashrate, share e soglia payout
- Publisher Validator per controllare siti prima della pubblicazione
- Zone Explorer per aprire zone pubblicate
- Velora Login Tester per verificare il login unificato nei siti
- Mail Tester per preparare test VeloMail
- Node Health per stato nodo, rete e identita locale
- Hash Verifier per SHA-256
- Recovery Key Check per controllo key token
- Report Abuse per segnalazioni ordinate

## Funzioni Velora gia presenti nella beta
- Account Velora con registrazione, login e sessione persistente
- Identita dispositivo e recovery key personale
- VeloMail persistente tra utenti Velora
- Forum e chat globale con messaggi salvati
- Publisher Studio per preparare, controllare e pubblicare siti
- Motore di ricerca interno con siti, zone e tools
- Apertura reale delle zone pubblicate dentro Velora
- Pagina pubblica per ogni zona
- Mining Partner con configurazione worker, potenza CPU, stato locale, progressi e richiesta payout manuale
- Dashboard mining con potenza collettiva e soglia payout
- Nodi utente con identita locale
- Admin web per utenti, nodi, mining, payout, siti, segnalazioni, audit e health
- Download Windows e macOS beta con manifest, hash e changelog
- Aggiornamento desktop tramite controllo versione
- NAS fallback agent scaricabile
- Sicurezza con rate limit, audit e messaggi piu chiari

Velora non sostituisce Internet: lo eleva con identita, strumenti, pubblicazione, ricerca interna, nodi e funzioni quotidiane integrate.
