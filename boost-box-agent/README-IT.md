# Velora Boost Box Agent - IT

Agente software beta per testare il concetto Boost Box su mini PC, thin client o SBC compatibile.

Stato reale: software predisposto, hardware industriale non prodotto.

Non contiene wallet, seed, password utente o accesso VeloMail.
Non offre shell remota generica.
Il controller puo inviare solo operazioni tipizzate.
