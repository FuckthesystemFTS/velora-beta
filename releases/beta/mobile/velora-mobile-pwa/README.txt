# Velora Mobile Beta

Apri https://www.webvelora.it/mobile da Safari, Chrome o browser Android/iOS.

Android: apri il menu del browser e scegli Installa app.
iPhone/iPad: premi Condividi e scegli Aggiungi alla schermata Home.

Funzioni incluse: account Velora, tools, Cloud, forum, mining monitor, nodi e payout manuale.
